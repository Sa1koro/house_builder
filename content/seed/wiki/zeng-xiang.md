# 增项

## 是什么

签约套餐范围之外、施工过程中另行收费的项目。装修纠纷与超预算的第一来源。

## 高发增项清单

| 类别 | 说明 |
| --- | --- |
| 拆改 | 套餐几乎都不含，按实结算 |
| 水电超量 | 点位/米数超出套餐包含量 |
| 定制超量 | 本案套餐含 15㎡，超出按单价另计 |
| 特殊基层 | 墙面空鼓铲除、找平层加厚 |
| 防水加高 | 上返高度超标准段 |
| 封窗/新风/地暖 | 套餐外系统性工程 |

## 控增项方法

1. 签约前逐条确认「不含项」清单并写入合同；
2. 要求给出常见增项**单价表**（如超面积 699/799 元/㎡、实木芯 +3000）；
3. 开工交底时对增项现场确认签字，拒绝口头报价；
4. 合同约定增项总额上限（如 ≤5%）。

## 本示例中的待确认项

淋浴房是否计入 AEs；管理费基数；15㎡ 定制不够时的增项单价；拆改/新风/地暖是否另计。
