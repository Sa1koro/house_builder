# Public seed content

The executable seed is `packages/supabase/seed.sql`. It contains 20 terms,
20 brands, generated Wiki pages, and the public AEs/A5s comparison.

Seed entries are intentionally factual and conservative. `tier` is a rough
market-position label for comparing a package's selectable brand pool, not a
quality guarantee or endorsement. Enriched entries are marked `source=enrich`
and carry lower initial confidence so an editorial workflow can review them.
